# 人生清单 · 200 条候选

面板上一共 **100 盏灯**（人生大事件也各占一盏）。从这 200 条里挑出属于你的，再加上你自己的人生大事件。

**怎么勾选**
- 做到过的：把 `[ ]` 改成 `[x]`，后面空一格写年份（选填），例如 `- [x] 学会游泳 2012`
- 还没做、但想做的：保持 `[ ]`
- 不想要的：整行删掉
- 想加自己的：照格式另起一行
- 人生大事件：写在最后「人生大事件」一节，每行 `- 年份 事件`（会亮冷白色的灯）

**改完后运行**（总数超过 100 会提示还要删几条）：

```sh
node scripts/import-lifelist.mjs
```
