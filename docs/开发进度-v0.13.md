# v0.13 · 2026-09-24

## 本轮交互模型
机票下缘接近槽口，弹簧将其沿 y 轴轻吸入 16px。机器前沿作为真实前景遮挡，而非靠淡出或缩小伪造插入。插入后松手停在 READING；沿槽从左向右刷至终点 SUCCESS；中途向上拔出 ERROR，可重新插入。鼠标轻点不替代刷卡，键盘 Enter 有等效自动路径。
光盘按住时可推进/撤回，只有在插入状态松手才触发 1.3 秒吸入。自由放置的物件闲置 2.6 秒后使用较软的弹簧归位；再拿起会取消归位。resize/Escape/切换模块取消在途动画与计时器。
机器切换取消延迟，以 130ms 退出 / 190ms 进入的短横移替代旧长淡入。内容路由使用 440ms FRED. 遮罩转场，无伪进度条。
