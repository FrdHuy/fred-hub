# Fred’s Hub 设计语言 · Soft Retro Industrial（温和的复古工业设计）

> 一张 1975–1990 年设计师的书桌：每件收藏都是那个年代的一件精致物件或纸品。
> 参照：Dieter Rams / 博朗的功能主义、八十年代日本消费电子（Sony、早期无印良品）、Teenage Engineering 的当代复刻。
> 由 Fred 于 2026-09-28 确认。所有 agent（Claude、Codex/GPT）做任何视觉或交互改动前先读本文件；偏离需先征得 Fred 同意。

## 一句话判断
新东西放到首页，是否像**同一个品牌、同一年代的产品家族**里的一员？像登机牌、光驱、读卡器那样——是就对了。

## 六条原则

1. **少，但更好（Less, but better）**
   没有装饰性文字、标题、说明；能用简笔线稿图标或物件本身表达的就不用字。每个元素都要有用途。

2. **物件先于界面**
   每个模块的入口是那个年代的一件物件/设备/纸品（登机牌、光盘与光驱、控制面板、台历……），不是网页按钮或卡片。

3. **克制的色彩**
   - 外壳与纸：暖白 `#f8f5f2` 底，米白 `#f5f1e5`/`#e8e5d9`，灰绿 `#e0e2dd`→`#bfc6bd`，深灰绿文字 `#4b5549`。
   - **唯一强调色：砖红 `#b34934`**（`Fred.` 的句点，相当于博朗的橙色）。**每个模块（每件首页物件、每个内页）只点一处**：机票上的 ✈、光盘标签的句点、面板的拨杆头、内页丝印的圆点。
   - 功能色只用于有意义的状态：指示灯绿、琥珀色灯、液晶屏深色 `#2f332f`。
   - 不用高饱和的大面积颜色。

4. **真实但干净的材质与统一的光**
   哑光塑料、拉丝金属、纸张、玻璃灯罩。光源统一在**左上方**，柔和的棚拍光：高光带、侧暗、底部接触阴影。
   **不做写实的装饰纹理**（木纹、竹纤维、宣纸肌理这类会让物件变成“工艺品”）；只允许极轻的颗粒或纸感。

5. **字体**
   - 英文与数字：等宽体（`ui-monospace, SF Mono, Menlo`），大写、加宽字距，像设备上的丝印标签（`BOARDING PASS`、`READY`、`Nº 005`）。
   - 中文：苹方细体（界面、读数）或宋体细体（内页正文、标题）。
   - 数字可以当作仪表读数使用（`023/100`）。

6. **机械动作 + 状态反馈**
   每个交互对应一个真实的机械动作（插入、刷过、推入、拨动、拉下），并有设备式反馈：`READY → READING → SUCCESS / ERROR`、指示灯、液晶读数。要有阈值：不够就回弹或失败。这是机票交互惊艳的原因。

## 首页与内页
- **首页：严格统一。** 所有物件共享以上色彩、材质、光线、字体；横滑切换收藏，纵向动作操作物件（v0.25 手势规则）。
- **内页：可以是“同一栋楼的不同房间”。** 允许有自己的气质（片单是深色放映室），但仍然：同一套字体体系、强调色克制、少文字、同样的光线逻辑。
- 越界的例子：竹制签筒 + 宣纸手卷（民俗工艺品气质，已放弃）。

## 交互与无障碍（不变的底线）
横滑=切换收藏，纵向=物件；轻点有等价的自动动作；键盘可操作；`prefers-reduced-motion` 直接切换；焦点框只给键盘用户；内页不是嵌套弹窗。

## 检查清单（交付前自查）
- [ ] 放在机票、光驱旁边截图对比，看起来是同一家族吗？
- [ ] 除了物件本身和必要的读数，页面上还有没有可以删掉的字？
- [ ] 这个模块的砖红是否恰好一处？
- [ ] 光是不是从左上来？有没有写实装饰纹理？
- [ ] 手势是一个真实的机械动作，并且有反馈和阈值吗？
