# v0.15 · 手稿人生清单 · 2026-09-28

用户认可光盘、书本、机票；暂撤罗盘，以人生清单作为第四件收藏。

设计：暖白单页、灰绿铅笔字、纸夹、折角、砖红色划线与星号；点击纸张轻微抬起舒展，进入独立清单页。内页使用楷体、留白和细纸纹。勾选原生复选框后，原位文字被细横线划掉并淡化；支持键盘。

功能：新增（最多200字符）、完成/取消、移除及单步撤销。空数据开始，封面文字是装饰。数据位于当前浏览器 localStorage 的 fred.hub.bucketlist.v1；读取异常不覆盖原记录，保存异常显示提示。没有账户、云同步和数据导出。

改动：catalog、gallery 的 catalog 版本引用、main 缩略图作用域、experience 新增 bucketlist 打开分支、index 样式引入、modules/index 注册；新增 bucketlist 三文件；旧 wheel 源码保留。光盘/机票/日记交互逻辑保持。

验证：check.mjs、check-gallery.mjs、check-bucketlist.mjs；浏览器菜单入口、封面排版、添加条目、勾选横线、刷新保留完成状态、移除撤销。测试条目已清理。窄封面文字已按物件尺寸缩放；未做完整设备矩阵。

项目位于桌面 Project/Fred-Personal-Site。checkpoint v0.14 保存旧版。下一阶段等待 Fred 对纸张的体验反馈，再逐一优化模块内部。
