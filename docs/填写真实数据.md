# 填写真实数据

网站上的内容都只有你能改。三个模块、三种办法，改完推送到 GitHub 就会上线。
命令都在项目文件夹的终端里运行（在访达里右键项目文件夹 →「新建位于文件夹位置的终端窗口」）。

## 1. 电影与剧集
现在的 5 部是示例。
1. 加一部：`node scripts/add-movie.mjs 花样年华 4.5`（片名 + 评分，评分可不写），按提示选编号，海报会自动下载。
2. 删掉示例：打开 `dist/modules/cinema/data.js`，删掉不要的那几行。

更多用法见 `docs/片单使用说明.md`。

## 2. 旅行足迹
现在的行程都是占位。
1. 打开 `docs/旅行行程-填写.md`，照着「例」往下填（空着的格子不用管）。
2. 照片放进 `dist/modules/travel/photos/`，在表里写上文件名。
3. 运行 `node scripts/import-travel.mjs`。

首页登机牌会自动显示下一班（想去的地方里最近定了日期的那一趟）。

## 3. 人生清单
已经是你的真实清单（66 条）。
1. 打开 `docs/人生清单候选-200.md`，勾选 `[x]`，后面可以写年份（如 `[x] 学会游泳 2012`）。
2. 运行 `node scripts/import-lifelist.mjs --force`。

## 改完之后
- 预览：双击项目里的「启动预览.command」。
- 上线：告诉 Claude「推送」，或者自己 `git add -A && git commit -m "更新内容" && git push`。
