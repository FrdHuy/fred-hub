# 填写真实数据

网站上的内容都只有你能改。四个模块、四种办法，改完推送到 GitHub 就会上线。
命令都在项目文件夹的终端里运行（在访达里右键项目文件夹 →「新建位于文件夹位置的终端窗口」）。

## 1. 电影与剧集
现在的 5 部是示例。
1. **一次加很多部**：运行 `node scripts/cinema-picker.mjs`，浏览器会打开海报墙——看过的点一下，最后点「保存到片单」（评分自动用 TMDB 上的分数）。按年份翻最容易想起来。
2. 删掉示例：在勾选器的「我的片单」里点一下那几部（标成移除）再保存，或者直接删 `dist/modules/cinema/data.js` 里那几行。
3. 只加一部也可以：`node scripts/add-movie.mjs 花样年华`。

更多用法见 `docs/片单使用说明.md`。

## 2. 旅行足迹
现在的行程都是占位。
1. 打开 `docs/旅行行程-填写.md`，照着「例」往下填（空着的格子不用管）。
2. 照片放进 `dist/modules/travel/photos/`，在表里写上文件名。
3. 运行 `node scripts/import-travel.mjs`。

首页登机牌会自动显示下一班（想去的地方里最近定了日期的那一趟）。

## 3. 人生清单
已经是你的真实清单（66 条）。
1. 打开 `docs/人生清单候选-200.md`，勾选 `[x]`，后面可以写年份（如 `[x] 学会游泳 2012`）。
2. 运行 `node scripts/import-lifelist.mjs --force`。

## 4. 手记
现在的 4 篇是占位（私密示例的暗号是 fred）。
1. 在 `notes/` 里新建一个 `.md` 文件，照着 `notes/README.md` 写（开头写标题、日期、类型；想加密就写一行「暗号」）。照片放同一个文件夹。
2. 运行 `node scripts/publish-notes.mjs`。
3. 删掉不要的占位文章（`notes/` 里那几个带“（占位）”的文件），再运行一次。

## 改完之后
- 预览：双击项目里的「启动预览.command」。
- 上线：告诉 Claude「推送」，或者自己 `git add -A && git commit -m "更新内容" && git push`。
