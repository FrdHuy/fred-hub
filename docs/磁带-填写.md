# 磁带：怎么录歌

1. 终端运行 `node scripts/music-picker.mjs`，浏览器会打开「录音台」（只在这台电脑上）。
2. 左边选一盒磁带，或点「＋ 新磁带」；改名字、选颜色（4 种），可以写一句话。
3. 右边搜歌（中文歌选「台湾」或「香港」更容易找到），点 **A** 或 **B** 放进那一面。
4. 行尾的按钮：▶ 试听 · ↑↓ 调顺序 · ⇄ 移到另一面 · ✕ 拿掉。
5. **想放整首**：把你自己的 mp3 / m4a 文件拖到那一行上（文件会复制到 `dist/modules/music/audio/`）。不拖就放苹果的 30 秒试听。
6. 点「保存到网站」，然后 `git push`，网站就更新了。

提醒：网站是公开的，放整首歌的文件相当于公开分发；只用试听片段最稳妥。
