# 部署：GitHub + Vercel + fredhu.top

网站是纯静态文件，Vercel 只需要发布 `dist/` 文件夹，不需要构建。`.env`（TMDB Token）和 `checkpoints/` 不在 git 里，不会被上传。

## 一次性设置

1. **GitHub**：在 github.com 新建一个**私有**仓库（例如 `fred-hub`），不要勾选 README / .gitignore / License。把仓库的 HTTPS 地址交给 Claude 或 Codex 推送，或自己运行：
   ```sh
   git remote add origin https://github.com/<你的用户名>/fred-hub.git
   git push -u origin main
   ```
   本机 SSH（22/443）被代理拦截，所以用 HTTPS 地址。第一次推送会要求登录 GitHub。

2. **Vercel**：vercel.com → Add New → Project → 导入这个仓库，然后设置：
   - Framework Preset：**Other**
   - Root Directory：**dist**
   - Build Command / Output Directory：留空
   - 点 Deploy，得到一个 `xxx.vercel.app` 地址，先在那里检查一遍。

3. **域名**：Vercel 项目 → Settings → Domains，添加 `fredhu.top` 和 `www.fredhu.top`（选择 www 跳转到 fredhu.top）。Vercel 会显示需要添加的解析记录，以它显示的为准，通常是：

   | 主机记录 | 类型 | 记录值 |
   | --- | --- | --- |
   | `@` | A | Vercel 显示的 IP（常见为 `76.76.21.21`） |
   | `www` | CNAME | Vercel 显示的地址（常见为 `cname.vercel-dns.com`） |

   在阿里云控制台 → 云解析 DNS → `fredhu.top` → 添加上面两条；如果已有 `@` 或 `www` 的旧记录，先删除或暂停。几分钟到几小时生效，Vercel 会自动配置 HTTPS。

## 以后更新

改完代码 → `git push` → Vercel 自动上线（约 1 分钟）。每次发版继续按惯例递增 `?v=` 版本号，访客就不会拿到旧缓存。

## 注意

- `.top` 域名须在阿里云完成**实名认证**，否则解析不生效（状态显示 serverHold）。
- Vercel 服务器在境外，不需要 ICP 备案；但中国大陆访问速度可能偏慢，个别网络可能不稳定。
- 人生清单与片单一样是数据文件（dist/modules/bucketlist/data.js），所有访客看到同一份。
