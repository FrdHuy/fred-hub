## 目标
把「故事与日记」（模块 id `stories`）当前平庸的“日记本翻开”交互，替换为**撕页日历**：一本老式手撕日历，最上面一页显示最近一篇日记的日期；手指/鼠标按住往下拉，纸页受力拉伸、边缘出现锯齿，超过阈值后“撕”下并飘落，随后进入日记内容。拉不够就回弹。

## 设计语言（2026-09-28 新增，最重要）
整站统一为 **Soft Retro Industrial（温和的复古工业设计）**，详见 `docs/DESIGN.md`。对撕页日历意味着：做成**博朗 / 七八十年代设计师桌面台历**的气质——米白纸、等宽体数字、灰绿或米白的底座/夹子、砖红只点一处，左上柔光；**不要**老黄历、宣纸、木纹这类民俗工艺品质感（人生清单的竹签筒就是因此被否决的）。放到机票、光驱旁边必须像同一产品家族。

## 设计标准（来自网站里最成功的“机票刷卡”交互，必须满足）
- **真实世界里人人做过的动作**，不用任何文字说明就会操作。
- **有物理反馈和阈值**：受力、拉伸、回弹、撕裂瞬间；可能“失败”才显得真实。
- **物件本身就是内容隐喻**：日记 = 每一天 = 日历页。
- **短**：1–2 秒完成。
- **界面文字越少越好**：Fred 明确不喜欢多余文字，偏好简笔线稿图标代替文字标签；整体要细腻、精致，不要粗糙。
- 每个模块进入后可以有**独立的视觉风格**，不必呼应首页（先征得 Fred 同意）。

## 技术约束
- 原生 HTML / CSS / ES Modules，`dist/` 就是源码，无构建、无 npm 依赖。**引入任何新库、字体文件或新设计语言前先问 Fred。**
- 模块入口：`dist/modules/stories/index.js` 同步 `mount({container,item,navigate,createCover})` 返回 cleanup；异步工作在 mount 内启动并由 cleanup 取消；事件用 `AbortController` 的 `signal`。
- 模块样式放 `dist/modules/stories/style.css`，所有选择器以 `[data-module="stories"]` 开头；需要在 `dist/index.html` 加样式链接。
- 首页物件与手势：`dist/catalog.js`（`createCover` 里 stories 封面）、`dist/experience.js`（`activate()` 里的 `stories` 分支，目前是 `journal-unfolding`）。**v0.25 的规则要保留**：按在物件上先观察约 7px，横向交给收藏轨道滑动，纵向才拿起物件——撕页是向下拉，天然符合。
- 必须支持：键盘等价操作（如 Enter/空格直接撕下）、`prefers-reduced-motion`（直接切换）、触屏、375px 手机宽度。焦点框只给键盘用户（v0.24 的 `html[data-input]` 机制已处理，别再加红框）。
- 资源版本号：发版时把所有 `?v=26` 统一递增。
