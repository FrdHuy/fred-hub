# 人生清单 · 求签筒 设计 · 2026-09-28

状态：用户已确认，Claude Code 实现（分支 `claude/fortune-sticks`）。

## 用户决定
- 首页原地摇签，点掉出的签再进入完整清单（不离开首页就有惊喜）。
- 手势：按住**上下**摇（真实求签是前倾上下摇；且不与首页横滑切换冲突）；手机可真摇（iPhone 首次点签筒请求动作权限）。
- 签面：签号 + 愿望 + 已完成盖朱红「已成」印。
- 内页：竖排签文长卷，从右往左，每件愿望一列，朱红细线分格，已成盖印。
- 重点：质感——恰当的光影与纹理。

## 首页物件
- 竹签筒（SVG）：左上主光；圆柱明暗（暗边—高光带—中间调—反光边）；feTurbulence 竹纤维纹理；两道竹节（凸棱高光+下方阴影）；筒口椭圆内壁暗部；接触阴影；阴刻「人生」。
- 竹签（HTML）：木色渐变与纤维，朱漆签头带高光；在筒口后方、筒身前壁之前遮挡。
- 摇：竖向拿起后签筒随手指上下（带限幅、前倾），每次方向反转且幅度足够计一摇：签子随机跳动、被选中的签逐步上升；4 摇后签滑出、翻转落在筒前（横卧、略斜，签面横排：第 N 签 · 愿望 · 已成印）。未摇够松手：签落回。
- 轻点签筒：自动摇三下并出签（与轻点光盘自动读取一致）；iPhone 同时请求动作权限。
- 再次摇：地上的签先收回。点地上的签：进入清单页（签→长卷的展开过渡）。
- 键盘：选中时 Enter 出签，再 Enter 打开。reduced-motion：直接出签。空清单：空签「尚未落笔」。
- 随机不与上一根重复。

## 清单页（长卷）
- 上下木轴（圆柱光影 + 轴头），宣纸纤维纹理，朱红细线分格；右起标题列「人生清单」，每件愿望一列（竖排宋体，列底中文数字），已成字迹变淡 + 不规则边缘的朱红印；最左列「已成 x / n」与落款。
- 打开时从右向左展开；横向滚动（滚轮/拖动/触控），起始在最右。

## 结构
- `modules/bucketlist/cover.js`：签筒封面 HTML（唯一 id，Node 可导入）。
- `modules/bucketlist/fortune.js`：首页摇签控制器（抽签、签子动画、落签、设备摇动）。纯逻辑（摇动计数、抽签不重复、中文数字）可在 Node 测试。
- `modules/bucketlist/index.js` + `style.css`：长卷页与封面样式（封面用容器单位，菜单缩略图同样适配）。
- 共享：`catalog.js` 封面改调 `fortuneCover()`；`experience.js` 手势路由到控制器；`main.js` 打开动画起点改为掉落的签、终点为长卷。
