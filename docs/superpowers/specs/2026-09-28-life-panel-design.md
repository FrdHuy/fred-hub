# 人生清单 · 百灯控制面板 · 2026-09-28

状态：Fred 确认设计图后实现（Claude Code，分支 claude/life-panel，已合入 main，资源 v28）。取代已放弃的竹签筒方案（历史在分支 claude/fortune-sticks）。遵守 docs/DESIGN.md。

## 首页物件
- 米白机身 + 灰绿凹槽灯区 + 四角螺丝 + 丝印铭牌 `LIFE LIST / Nº 100 · FRED` + 液晶屏（`888/888` 底纹）+ 金属拨杆（杆头是首页唯一的砖红）。
- 10×10 灯：写了内容的是玻璃灯罩，未写的是空灯座；待机全部熄灭。
- 手势：纵向拖动任意位置 = 拨杆（有阻力，过阈值 0.62 才卡到 ON，否则回弹）；轻点 / 回车 = 自动拨上。
- 通电：液晶 `TEST` → 已写的灯按顺序闪一遍 → 落到真实状态（琥珀 = 做过，暗暖 = 未做）→ 数字 000 滚到进度 → 面板放大进入内页。

## 内页（deck）
- 读数屏：`Nº 005` / 内容 / `● DONE · 2023`、`○ SOMEDAY`、`○ NOT YET · 2023`（回看时尚未做到）/ `年份 · 023/100`。
- 灯阵：鼠标悬停、点击、方向键（←→ 一件，↑↓ 一行）选择，选中灯外有白色细圈。
- 年份里程表：四位滚筒，上下拖动 / 滚轮 / ↑↓ 一年一格；回看到过去，只亮那年之前做到的事（无年份的已完成事项只在今年亮）。
- 选择旋钮：滚花铝旋钮，24° 一个档位，拖动旋转 / 滚轮 / 方向键；刻度环。
- PRINT：有行程的按键；热敏纸从底部出纸口逐行吐出完整清单（按当前年份）。
- 读屏：隐藏的完整列表 + 各控件 role（listbox/option、spinbutton、slider）。

## 数据
`data.js`：`{ text, done, year? }`，year 仅在 done 时填写（1900–2100）。最多 100 件。

## 结构
`panel.js`（纯逻辑：灯状态、回看、年份范围、旋钮档位、拨杆行程）· `cover.js`（首页面板 HTML）· `panel-home.js`（首页控制器）· `index.js`（内页）· `style.css`。共享：catalog 封面、experience 手势、main 打开动画（小面板 FLIP 放大为 deck）、hub.css 清单页返回改为简笔箭头。
