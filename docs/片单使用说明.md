# 片单使用说明

只有你能改片单：网站是静态的，访客没有任何写入途径；内容就是 `dist/modules/cinema/` 里的 `data.js` 和 `posters/`。

## 加一部（推荐）

在项目根目录的终端里：

```sh
node scripts/add-movie.mjs 花样年华 4.5
```

- 海报自动选原版（中国片中文、法国片法语…），书脊仍显示中文片名。已有影片可用 `node scripts/add-movie.mjs --posters` 一次性换成原版。
- 从列出的结果里输入编号。评分可省略，脚本会再问你（回车跳过）。
- 自动填好原名、年份、类型、导演（剧集为主创），下载海报，插到片单最前面。
- 已在片单里的片子会提示并跳过。
- 需要项目根目录 `.env` 里有 `TMDB_TOKEN=…`（不会进入 git，也不会出现在网站上）。
- 连不上 TMDB 时，在 `.env` 里再加一行代理，例如 `HTTPS_PROXY=http://127.0.0.1:7890`（端口看你的代理软件）。

## 手动改

打开 `dist/modules/cinema/data.js`，一部一行，越靠上越先放映：

```js
{ title: "花样年华", original: "花樣年華", type: "电影", year: 2000, director: "王家卫", rating: 5, poster: "movie-843.jpg" },
```

- 只有 `title` 必填；不写的字段页面上就不显示。
- `type`：`"电影"` 或 `"剧集"`；`rating`：0–5，可写 4.5；`poster`：`posters/` 里的文件名。
- 调整顺序 = 剪切整行粘到别处。删除 = 删掉整行（海报文件可一并删除）。
- 每行末尾的逗号不能少。

## 检查与发布

```sh
node scripts/check-cinema.mjs
```

会指出哪一行有问题、哪张海报找不到。通过后刷新预览看效果，再发布网站。页面本身也会提示出错的条目，其余影片照常显示。
