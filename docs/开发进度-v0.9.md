## 已确认要求

名称 Fred’s Hub，保留 Fred. 标识。两种模板：Jackie 式生活桌面 / 横向收藏。移除通用向下拖放。光碟取出装入 CD 机，旅行机票刷入，书本摊开，罗盘旋转选择。留白与入场切换参考 Hishaam。

## 本轮实现

- 桌面 / 横版切换，同一注册表与模块路由；本地只记布局偏好。
- 桌面中央保留介绍，两侧生活物件，手机双列错落；增加物件时可继续向下延展。
- 移除通用拖放打开区；保留横版拖动吸附、分类保留当前物件。
- CD：打开盒盖 → 取出 → 拖进播放器/点击播放器放入 → 读取并进入片单。
- 旅行：向右刷机票进读卡器，也有点击替代。
- 日记：封面翻开，展开双页，再进入故事页。
- 罗盘：黄铜实物底图和独立针，旋转 5 圈以上后对准选项。可填 2–8 项。
- Fred 简短入场、模板淡入位移、减少动态效果兼容；Escape 可取消物件操作。
