# 扭蛋机 · 设计记录（与 Fred 逐项讨论确定，2026-09-30）

视觉稿：`gashapon-v1.html` … `gashapon-v7.html`（浏览器直接打开）。**当前定稿 = v5 的 B1 机身 + v7 的 D 磨砂灯蛋。**

## 内容与规则
- 两种内容：**今日签**（黄历 + 星座）与**真心话大冒险**（朋友聚会时一起玩，主要在手机上）。
- 切换：机身**侧边滑块**两档（签 / 游戏）。扭蛋外观不区分内容：拧开是签还是题，由滑块档位决定。
- 星座：机身上的小**星座旋钮**，可以随时拨（想看几个星座就拨几个）。同一天、同一星座永远是同一张签。
- 签：**传统正经**。黄历真实计算（农历、干支、建除十二神宜忌）；运势 = 签等（上上 / 上 / 中 / 下）+ 观音灵签四句签诗 + 解曰（原文从公开来源整理、逐首核对）。竖排签纸。
- 游戏：一仓混装，**拧开才知道**是真心话还是大冒险；同一场不重复，题库扭完才重来。题库由 Fred 写（一行一题，「真：」/「冒：」开头）。
- 彩蛋：**多样化、随机**混在普通蛋里（灰绿 / 石灰 / 墨色 / 绿顶 / 全透明 / 印字 / 点点 / 条纹……），每次组合不同；另有极少出现的**特殊彩蛋 = D 磨砂灯蛋**（整颗磨砂玻璃，里面一盏暖光小灯一明一暗）。彩蛋里放 Fred 的特殊内容，**暂用占位**。

## 物件（首页）
- **正面平视**（与机票、打字机、面板一致）。不用 CSS 3D，不用斜轴测。
- **B1**：圆角暖白顶盖 + 圆角暖白底座（都比仓宽一圈）夹住**淡灰绿半透明亚克力仓**；两只小脚。
- 深度：仓左右两侧更深的灰绿 = 亚克力厚度；扭蛋分前 / 中 / 后三层，越往后越被亚克力染色。
- 底座：小星座旋钮（12 个星座符号印成一小圈）· 缎面铝扭把（T 形横杆）+ **砖红握柄帽（唯一的红）** · 出蛋口（深色内腔 + 烟色翻板）· 右边缘露出滑块拨杆，旁边两个小图标（签纸 / 骰子）· 左下 `Fred.`。
- **没有任何操作提示文字**；不要「07」之类无意义的丝印。
- 扭蛋：球体，上半透明、下半哑光暖白，中缝一圈；透明半能看到杯口和折起的纸条。

## 房间（v8，已确认）
- **机器 + 桌面**：扭蛋机在左（手机在上），右边一块干净的圆角浅色台面（不加材质）。
- 扭满一圈 → 蛋从出蛋口滚到桌上 → **按住画圈拧开**（上半跟着转，中缝错开，转到位「嗒」一声开；不够就合回去）→ 签纸 / 题卡摊在桌上；蛋壳留在一角。
- 连续扭：新的签纸 / 题卡盖在最上面，旧的往下叠、微微错开。特殊彩蛋（磨砂灯蛋）滚出来时亮着。
- 手机：桌上是一张**折着的小签**，点一下展开成整页阅读（电脑上直接摊开）。
