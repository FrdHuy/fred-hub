# 3D 小屋（#/room）设计与交接

> 2026-10-10 已合入 main 并上线（原分支 `claude/room-3d`）。Fred 2026-10-09 确认的方案。原来的横向收藏首页 `#/` 不变。

## Fred 的决定
- 花园里的温暖小木屋（不是雨夜便利店）：悬浮的切面地块，上面是草地、花、树、栅栏；小屋切开朝向镜头的两面墙。
- **光影质感是重点**。默认时刻：傍晚黄金时刻。天气和昼夜以后再做（`lights.js` 的 `MOODS` 预设表就是为它留的）。
- 颜色自由，**这一页不受「每个模块只点一处砖红」的限制**（DESIGN.md 已记为例外）。
- 3D 先放在 `#/room`，首页不动；满意后再决定是否换成首页。
- 点击物件：镜头推近 → 现有模块**整页**淡入（网址变成 `#/collection/<id>`，模块原样运行，加密流程不动）→ 返回 / Esc 时镜头拉回全景。
- **可以绕着小屋转一整圈**（Fred 2026-10-09 追加）：四面墙都有，挡在镜头和房间之间的那面自动隐去（`cutaway.js`），挂在墙上的东西跟着隐去。隐去只是材质淡到透明，墙照样挡太阳，所以转动镜头不改变屋里的光影。东墙、南墙（默认视角下隐去的两面）不投影。
- 摄影、雪山计划、技术项目三个模块还没建：对应物件先做成摆设（`config.js` 里 `soon: true`，悬停显示名字、不可点）。

## 物件 ↔ 模块（`dist/room/config.js`）
书桌 + 台灯 + 打字机 → 手记 ｜ 冰箱 → 旅行 ｜ 小电视 + 光盘 → 电影与剧集 ｜ 扭蛋机 → 扭蛋机 ｜ 墙上的百灯板 → 人生清单 ｜ 拍立得墙 / 雪山海报 / 电脑屏幕 → soon。
增删模块只改这个数组；新造型 = 新增 `objects/<名字>.js`（导出 `build()`）并在 `objects/index.js` 登记。

## 技术
- Three.js **0.170.0**，自托管在 `dist/vendor/three-0.170.0/`（`node scripts/vendor-three.mjs` 从 registry.npmmirror.com 下载，addons 里的裸模块名改成相对路径，不用 importmap）。运行时不请求任何第三方源。只在进入 `#/room` 时动态加载，其他页面不受影响。
- 所有几何体由代码生成（`kit.js` 的 box / cyl / ball / rod），贴图用 2D 画布现画（`paint`），没有模型和图片文件。
- `dist/room/` 内部互相导入**不带 `?v=` 版本号**（否则同一个文件会被当成两个模块，Three.js 和材质缓存会出现两份）；只有 main.js 导入 `room/index.js` 时带。
- 坐标：1 单位 ≈ 1 米，地板 y = 0，房间 x / z 从 -3 到 3；左后墙 x = -3（有窗），右后墙 z = -3；镜头在 +x +z。
- 灯位：物件里放名为 `light:<名字>` 的空节点，`lights.js` 按 `LAMPS` 表统一装灯。投影的只有太阳、台灯、落地灯。
- 光影手法：低角度暖色平行光穿窗（窗棂投出窗格）+ 偏冷的半球天光补暗部 + 物件脚下的接触阴影贴片（代替 SSAO）+ 叠加混合的光束和微尘 + ACES 色调映射 + 轻雾。
- 镜头：小视角透视（24°）远机位模拟等距；OrbitControls 方位角不限（可转 360°）、俯仰 40°–73°、距离 0.42–1.12 倍适配距离，不能平移。
- 交互（`interact.js`）：射线拾取 → 物件泛暖光 + 微微放大 + HTML 名称标签；点击 → `view.closeUp()` 沿弧线推近（950ms 缓入缓出）→ 过渡幕淡成模块页底色 → main.js 改网址进模块页。返回箭头 / Esc / 浏览器后退 → `#/room` → 幕布淡开、`view.back()` 拉回推近前的角度。
- 从小屋进模块页时 main.js 记 `roomReturn = true`：返回箭头、Esc、模块自己调用的 `navigate()` 都回小屋；直接打开模块网址或从首页进入时仍回首页。手记会自己把返回箭头改成 `#/`，main.js 用一个点击拦截处理，**没有改任何模块**。
- 键盘 / 读屏：`#room-view` 里有一组看不见但可聚焦的真链接（每个物件一个，`href` 就是模块网址）。Tab 或方向键移动 = 悬停，回车 = 点击，Esc 放开；还没建的模块是 `aria-disabled` 的按钮。
- 每件按配置摆放的物件有自己的一份材质（`kit.own()`），高亮和隐去互不影响别的物件。
- 渲染循环只在「当前是 #/room」且「标签页可见」时运行。像素比上限 2。

## 分阶段
1. ✅ 静态场景 + 灯光 + 镜头（本次）。
2. ✅ 悬停高亮 + 名称标签、点击推近 + 模块整页淡入、返回拉回全景、键盘导航 / Esc（`interact.js`）；可转到屋后（`cutaway.js`）。
3. ✅ Bloom 辉光（`effects.js`）、性能档位与自动降级（`quality.js`）、静态截图 + 2D 导航（`flat.js`）、先看设备再加载（`enter.js`）。
4. 以后：昼夜与天气（雨、雪）。

## 时刻与天气（Fred 2026-10-10）
左下角一排简笔图标切换，选中的记在 localStorage `fred-room-mood`；默认仍是傍晚（`config.js` 的 `mood`）。静态版不变（始终是傍晚的截图）。

| 预设 | 样子 |
| --- | --- |
| golden 傍晚 | 原来的黄金时刻 |
| spring 春 | 清晨：低角度的淡金色阳光、长影子、暗部偏青；树开粉花，花瓣飘落，地上有落花 |
| summer 夏夜 | 深蓝的天和星星（画在天空贴图里）、月光、萤火虫一明一灭，屋里灯亮着 |
| autumn 秋 | 晴朗的下午：蓝天配红黄的树，草还带绿，灌木有绿有红，落叶飘、地上铺落叶，花只剩两成 |
| winter 冬 | 阴天淡日，草地 / 树 / 灌木覆雪，墙顶、长椅、灯顶有积雪，下雪，没有花 |
| rain 雨夜 | 深蓝夜色 + 月光，灯更亮，雨丝 + 落地水花，草和石板变光滑（湿润高光） |

- 一条预设管到底：`lights.js` 的 `MOODS`（天空、雾、主光、天光、灯的倍数、曝光、光束、微尘、`garden` 花园配色、`weather` 落下的东西、`ink` 角落图标颜色）。`index.js` 的 `applyMood()` 依次调用 `lights.setMood` → `garden.setSeason` → `effects.setSun` → `weather.set`。
- 加一种天气：往 `MOODS` 加一条，在 `moodbar.js` 的 `ICONS` 里加同名图标（check-room 会检查）。
- 会换色的东西用 `kit.tone(名字, 颜色)` 建材质（grass、tree0–3、bush0–3、stone0–2、tuft、stem、petal、pollen、litter），`setSeason` 按名字改色；花、草丛、落叶是 InstancedMesh，用 `count` 控制数量。
- 主光始终从西墙的窗照进来，各预设只改高度、颜色、强度；换预设时光束按新方向重算。
- 雨雪只落在屋外（屋子没有顶）。数量随性能档位打折（档位 0 约三分之一）；`prefers-reduced-motion` 时停在半空不动。
- 云（`sky.js`，雨夜没有）：低处几朵绕着地块慢慢转；高处一朵挡在主光和花园之间，影子约一分钟扫过草地一趟。高处的云转到镜头和小屋之间时自动淡掉（照样投影）。预设里 `clouds` 是数量、`cloud` 是颜色。
- Fred 2026-10-10 的反馈：春夏秋第一版太平（光太正、天空空、只换了颜色、秋天一片橙）。改法是每季换一个更有戏的时刻、加云和云影、秋天配色拆开。季节专属的摆设（蝴蝶、向日葵、南瓜、落叶堆……）还没做，等 Fred 看过再定。
- 切换时画面先淡出 0.24 秒再亮起，没有做预设之间的连续渐变，也没有按真实时间 / 季节自动切换。

## 性能档位（`quality.js`）
| 档位 | 内容 |
| --- | --- |
| 4 | 全部：太阳 + 台灯 + 落地灯阴影（2048）、Bloom、全部微尘、像素比 ≤ 2 |
| 3 | 关两盏灯的阴影，太阳阴影 1024（手机起步档） |
| 2 | 关闭所有阴影 |
| 1 | 再关 Bloom，像素比 ≤ 1.5 |
| 0 | 微尘减到约 1/3，像素比 1 |
| flat | 没有 WebGL / 没有显卡加速（SwiftShader 等）/ 3D 加载出错：`fallback.jpg` + 普通链接，不下载 Three.js |

- 起点：桌面 4，手机 3；内存或核心数 ≤ 4 再减 1；已知弱显卡最高 1。运行中 60 帧平均超过 30ms 自动降一档，并记在 localStorage `fred-room-quality`。
- 测试：`?room=0…4` 固定档位，`?room=flat` 看静态版，例 `http://127.0.0.1:57123/?room=1#/room`。
- `prefers-reduced-motion`：镜头推近 / 拉回直接到位，微尘静止，高亮不做渐变。
- Bloom 参数在 `effects.js` 的 `BLOOM`（强度 .42、半径 .75、阈值 1.7，按线性亮度：只有灯、屏幕和最亮的阳光溢出）。
- 重新生成 `fallback.jpg`：场景改动后，用带显卡的无头 Chrome 打开 `?room=4#/room`（1600×1000），隐藏页眉后截图，`sips -s format jpeg -s formatOptions 82` 转成 JPEG。`scripts/dev/cdp.mjs` 默认带 `--disable-gpu`，要换成 `--use-angle=metal --enable-gpu`。

## 已知局限（第 3 阶段后）
- 入口：右上角菜单顶部的「收藏 / 小屋」切换（main.js `.view-switch`，Fred 2026-10-10）；首页本身不变。在小屋里点菜单里的模块缩略图仍然是回到收藏首页并对准那个模块。
- 降级只在带显卡的 Mac 上逐档验证过画面；真实的低端手机 / 弱显卡没有实测，自动降档的阈值是估的。
- 开关 Bloom 时天空颜色略有差别（两条渲染路径的色调映射位置不同）。
- 运行中 WebGL 上下文丢失没有处理（不会自动切到静态版）。
- 触屏：轻点直接进入（没有悬停这一步）；未建模块轻点后名字显示 1.6 秒。
- 窄屏（手机竖屏）推近后物件不一定在正中。
- 墙外侧没有单独的外墙造型（从外面看到的那面总是隐去的）；屋后的花园比前面简单。
- 未在真机手机和 Firefox / Safari 上测试。
