## Fred 的决定
- 花园里的温暖小木屋（不是雨夜便利店）：悬浮的切面地块，上面是草地、花、树、栅栏；小屋切开朝向镜头的两面墙。
- **光影质感是重点**。默认时刻：傍晚黄金时刻。天气和昼夜以后再做（`lights.js` 的 `MOODS` 预设表就是为它留的）。
- 颜色自由，**这一页不受「每个模块只点一处砖红」的限制**（DESIGN.md 已记为例外）。
- 3D 先放在 `#/room`，首页不动；满意后再决定是否换成首页。
- 点击物件：镜头推近 → 现有模块**整页**淡入（网址变成 `#/collection/<id>`，模块原样运行，加密流程不动）→ 返回 / Esc 时镜头拉回全景。
- 摄影、雪山计划、技术项目三个模块还没建：对应物件先做成摆设（`config.js` 里 `soon: true`，悬停显示名字、不可点）。

## 技术
- Three.js **0.170.0**，自托管在 `dist/vendor/three-0.170.0/`（`node scripts/vendor-three.mjs` 从 registry.npmmirror.com 下载，addons 里的裸模块名改成相对路径，不用 importmap）。运行时不请求任何第三方源。只在进入 `#/room` 时动态加载，其他页面不受影响。
- 所有几何体由代码生成（`kit.js` 的 box / cyl / ball / rod），贴图用 2D 画布现画（`paint`），没有模型和图片文件。
- `dist/room/` 内部互相导入**不带 `?v=` 版本号**（否则同一个文件会被当成两个模块，Three.js 和材质缓存会出现两份）；只有 main.js 导入 `room/index.js` 时带。
- 坐标：1 单位 ≈ 1 米，地板 y = 0，房间 x / z 从 -3 到 3；左后墙 x = -3（有窗），右后墙 z = -3；镜头在 +x +z。
- 灯位：物件里放名为 `light:<名字>` 的空节点，`lights.js` 按 `LAMPS` 表统一装灯。投影的只有太阳、台灯、落地灯。
- 光影手法：低角度暖色平行光穿窗（窗棂投出窗格）+ 偏冷的半球天光补暗部 + 物件脚下的接触阴影贴片（代替 SSAO）+ 叠加混合的光束和微尘 + ACES 色调映射 + 轻雾。
- 镜头：小视角透视（24°）远机位模拟等距；OrbitControls 方位角 45° ± 34°、俯仰 40°–73°、距离 0.45–1.12 倍适配距离，不能平移。
- 渲染循环只在「当前是 #/room」且「标签页可见」时运行。像素比上限 2。

## 分阶段
1. ✅ 静态场景 + 灯光 + 镜头（本次）。
2. 悬停高亮 + 名称标签、点击推近 + 模块整页淡入、返回拉回全景、键盘导航 / Esc（`interact.js`）。
3. Bloom 辉光、性能档位与降级（`quality.js`：关阴影 → 关 Bloom → 减粒子）、WebGL 不可用时的静态截图 + 2D 导航。
4. 以后：昼夜与天气（雨、雪）。

## 已知局限（第 1 阶段）
- 首页没有通往 `#/room` 的入口（Fred 决定首页不动），目前只能直接输入网址。
- 还没有悬停 / 点击；没有 Bloom；没有性能降级，WebGL 不可用时只显示一行字和回收藏室的链接。
