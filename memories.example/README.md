# 回忆怎么写（示例）

这个文件夹是**占位示例**（暗号 `cabin`），可以公开。你们真正的回忆放在项目根目录的 `memories/`——那个文件夹被 git 忽略，只留在这台电脑上。

1. 把 `memories.example/` 复制一份，改名为 `memories/`。
2. 改 `暗号.txt`：一句只有你们知道的话，越长越好（密文是公开的，短暗号会被试出来）。
3. 照着下面的格式改内容，然后运行 `node scripts/seal-memories.mjs`，再提交、推送。

| 文件 | 小屋里的物件 | 格式 |
| --- | --- | --- |
| `信/*.md` | 书桌上的打字机 | 开头 `标题：` `日期：` `来自：`，空一行，正文（段落之间空一行） |
| `纪念日.md` | 墙上的日历 | 第一行 `在一起：2024-05-20`，之后一行一件事：`日期 发生了什么 ｜ 备注` |
| `去过的地方.md` | 冰箱贴 | 一行一个：`日期 地点 ｜ 一句话` |
| `一起看过的.md` | 小电视 | 一行一部：`片名 ｜ 一句话` |
| `想去的地方.md` | 墙上的海报 | 一行一个：`地点 ｜ 一句话` |
| `小物件.md` | 屋里的摆设 | 一行一件：`名字 ｜ 它的来历` |
| `照片/` + `照片.md` | 拍立得照片墙 | 图片（jpg / png / heic）直接放进 `照片/`；想补日期或一句话，在 `照片.md` 写一行：`日期 文件名 ｜ 一句话` |

日期和 `｜` 后面的备注都可以不写。`#` 开头的行是注释。

照片会被缩小（小图 360px、大图 1600px）再加密，原图不会上传。墙上显示最新的 9 张，相册里是全部。
